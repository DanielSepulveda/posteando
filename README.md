# Posteando

Plan the month, get the client's yes from a link, and let everything publish itself. Posteando is a social media scheduling platform for agencies (and in-house teams), built for Mexico first and driven through MCP first.

This repository starts with the handoff package from the planning phase. There is no product code yet.

| Folder | What is in it |
| --- | --- |
| [`CLAUDE.md`](CLAUDE.md) | How build sessions work here, and what not to do |
| [`docs/`](docs/README.md) | Product, architecture, conventions, operations, MCP, network gateway, release plan, release 0 tasks, decisions, open questions, glossary |
| [`design/`](design/README.md) | The design system: tokens (JSON and CSS), components, fonts, logos and figures, principles and voice, app UI rules, reference mocks |

Start with [`docs/README.md`](docs/README.md).

The product domain (posteando.io or posteando.mx) is not chosen yet and must be fixed before the first deploy.
