# Toast

A short confirmation at the bottom centre, and the bulk-action bar that floats in the same place.

- A toast says what just happened in one sentence, in the product's voice: "Reintentando en TikTok con el audio nuevo." It leaves on its own after about four seconds.
- A failure is never only a toast: it stays on the object (the failed pill, the invalid field).
- The bulk bar is noir with card-coloured tools. It appears while rows are selected and leads with the count.
