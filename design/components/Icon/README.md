# Icon

A small set of line icons for the app's sections: a 16 grid, 1.6 stroke, round caps and joins, `currentColor`.

- Get them from `Posteando.icon(name)`: inicio, calendario, posts, biblioteca, numeros, marcas, chat, buscar.
- Icons only label navigation and search. Actions are words; state is a pill. Do not add an icon to a button to dress it up.
- New icons follow the same grid and stroke and stay geometric: no fills except a single dot, no two-tone.
- No emoji in product UI.
