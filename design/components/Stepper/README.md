# Stepper

The path of a post through its stages, in the second band of the Sheet.

- Done steps are noir discs with a check; the current step is ringed in its stage's highlighter (`--step-ink`); later steps are muted.
- It shows the stages this brand's policy actually uses: a brand that posts without approval has no "Con el cliente" step.
- It is a record, not a control. Moving a post is done with the sheet's primary button.
