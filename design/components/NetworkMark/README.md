# NetworkMark

A 19px noir disc with the network's mark in white, shown wherever a post lists where it goes.

- The glyphs in this preview are stand-ins drawn for the mock. The build must use each network's official logo files under that network's brand rules, in one colour on the noir disc where the rules allow it.
- Always with an accessible name ("Instagram", "TikTok", "Facebook").
- Several marks sit 3px apart in the order the agency connected them.
