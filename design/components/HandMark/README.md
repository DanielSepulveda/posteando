# HandMark

A hand-drawn cherry mark over type: a circle around a word or a wavy underline, as if someone marked the page with a pen.

- One hand-drawn mark per view. It may surround words but never crosses them.
- Stroke is `brand`, 3.2px, round caps, non-scaling, drawn slightly imperfect: the circle overshoots where it closes.
- It may draw itself once on arrival (about 900ms). It never loops.
- Website and the client portal's first screen only. In the app, emphasis is weight and the ink line; today in the calendar is a cherry border, not a circle.
