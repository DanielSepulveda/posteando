# Popover

Menus, filter popovers and the command palette (⌘K): a card with the ink line and a hard shadow, `shadow-pop` for popovers and `shadow-modal` for the palette over a `surface-scrim`.

- Hover is `surface-hover`. The keyboard-selected row is `surface-desk` with an inset ink outline. Never a pastel, never yellow: a highlight that looks like a warning is a bug.
- Each row is one line: what it is, then a mono label on the right saying what kind of thing it is.
- Filter popovers use checkboxes and apply at once; there is no "Apply" button.
- The palette finds posts, brands, sections and actions, and can start a helper.
