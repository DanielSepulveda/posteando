# Stamp

The rubber stamp: the record that a person approved something. Cherry double line, tilted 7 degrees, Allo at weight 900 with roundness 20, a mono line under it with who and when.

- It marks a human decision that is kept as a record: an approval, a hand-off. Never decoration, never a badge for a feature.
- One per object. It lands once with the `hit` class (220ms, `ease-stamp`) at the moment the decision is made, and is static ever after.
- It may overlap the corner of the thing it approves, never its text.
